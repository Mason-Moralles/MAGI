КТ № 6 Тестирование черного и белого ящика.

Зачем это учить?
Изолированные тесты хороши, но в реальном мире компоненты взаимодействуют. Интеграционный тест показывает, что после нажатия кнопки в браузере данные уходят в БД и возвращаются обратно. Это высший пилотаж для выпускника колледжа и демонстрация системного подхода.
Как это учить?
Проверить сквозной сценарий работы приложения, связав тесты уровня API, базы данных и пользовательского интерфейса.

Задание «Интеграционное тестирование (API + БД + UI)»
1. Выбери один сквозной бизнес-сценарий (например, «Пользователь регистрируется → логинится → создаёт заказ»).
2. Реализуй его в виде одного теста, который:
2.1 Через API создаёт тестовые данные (чистит БД или добавляет записи).
2.2 Через Selenium выполняет действия пользователя.
2.3 После каждого шага делает SQL-запросы для проверки состояния БД.
3. Убедись, что тест стабильно проходит.
4. Оформи код теста с комментариями — это будет частью приложения к диплому.
